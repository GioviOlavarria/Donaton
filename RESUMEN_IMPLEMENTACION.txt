## 🚀 Pasos para Usar

### 1. Iniciar el Sistema
```bash
cd C:\Users\pv-alumno\IdeaProjects\Donaton
docker-compose up --build -d
```

### 2. Esperar a que esté listo
```bash
# Verificar estado
docker-compose ps

# Esperar ~1-2 minutos
```

### 3. Acceder a través del navegador

| Rol | URL | Acción |
|-----|-----|--------|
| **Visitante** | http://localhost:8088/ | Ver página de inicio |
| **Admin** | http://localhost:8088/panel | Ver panel de control |
| **Donante** | http://localhost:8081/donantes/login | Registrarse/Iniciar sesión |
| **Beneficiario** | http://localhost:8082/beneficiarios/login | Registrarse/Iniciar sesión |

### 4. Usar el Sistema

**Como Donante:**
1. Ir a http://localhost:8081/donantes/login
2. Registrarse con un nuevo email
3. Iniciar sesión
4. Ir a http://localhost:8081/donantes/panel
5. Hacer clic en "Nueva Donación"
6. Completar formulario y enviar
7. Ver donaciones en el historial

**Como Beneficiario:**
1. Ir a http://localhost:8082/beneficiarios/login
2. Registrarse con un nuevo email
3. Iniciar sesión
4. Ir a http://localhost:8082/beneficiarios/panel
5. Hacer clic en "Solicitar Ayuda"
6. Completar formulario y enviar
7. Ver solicitudes en el historial

## 🔄 Integración con APIs

El frontend consume los siguientes endpoints:

### Autenticación
- `POST /api/auth/login` - Iniciar sesión
- `POST /api/auth/registro` - Registrarse
- `POST /api/auth/validar` - Validar token

### Datos
- `GET /api/donantes/{id}` - Obtener datos del donante
- `GET /api/beneficiarios/{id}` - Obtener datos del beneficiario
- `GET /api/centros` - Listar centros de acopio
- `GET /api/tipos-donacion` - Listar tipos de artículos
- `GET /api/donaciones/donante/{id}` - Donaciones de un donante
- `GET /api/donaciones/beneficiario/{id}` - Donaciones de un beneficiario
- `POST /api/donaciones` - Crear donación
- `PATCH /api/donaciones/{id}/estado` - Cambiar estado

### Admin
- `GET /api/admin/resumen` - Resumen del sistema
